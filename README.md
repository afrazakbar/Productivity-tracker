#Focus Focus
 
 
 Focus Focus is a simple and easy to use Productivity OS
 It has the following features:
  1. TODO List
  2. Pomodoro Timer
  3. Eisenhower method in the TODO List
  4. Catergory based sorting
  5. Easy to use interface
